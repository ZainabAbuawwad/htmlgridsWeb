# Lumen Photography Studio

A 10-page HTML5 & CSS3 website built for a web development assignment, showcasing a fictional photography studio's services, portfolio, and booking process.

## 🌐 Pages

| Page | File | Description |
|---|---|---|
| Home | `index.html` | Hero intro and service highlights |
| About | `about.html` | Studio background and philosophy |
| Services | `services.html` | Package pricing table |
| Portfolio | `portfolio.html` | Photo grid (CSS Grid) |
| Album | `album.html` | Behind-the-scenes gallery (Flexbox) + video reel |
| Blog | `blog.html` | Studio journal / recent posts |
| Contact | `contact.html` | Contact details + working form |
| Privacy Policy | `privacy-policy.html` | Data usage and photo policy |
| Return Policy | `return-policy.html` | Deposits, reshoots, digital delivery terms |
| Terms & Conditions | `terms.html` | Site usage and IP terms |

## 🛠️ Built With

- **HTML5** — semantic structure (`header`, `nav`, `main`, `section`, `footer`)
- **CSS3** — custom properties, Flexbox, CSS Grid, responsive media queries
- **Vanilla JavaScript** — mobile hamburger menu toggle
- **Google Fonts** — Playfair Display (headings) + Inter (body)

## ✨ Features

- Fully responsive layout with a mobile hamburger navigation menu
- Consistent header/footer across all pages
- CSS Grid-based portfolio gallery and Flexbox-based album gallery
- Embedded video and photo galleries (multimedia requirement)
- Working contact form with required-field validation
- Dark, editorial color theme with a warm gold accent
